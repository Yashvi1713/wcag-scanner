What every page goes through

  1. 01
    Rules

    axe-core checks contrast, names, labels and ARIA, on desktop and on a phone.

  2. 02
    Keyboard

    A scripted user presses Tab through the page: traps, invisible focus, controls a mouse can reach and a keyboard can't.

  3. 03
    Zoom and reflow

    200% zoom, wider text spacing and a 320 px screen. Does anything get cut off?

  4. 04
    Across the site

    Same navigation, same names, same help, unique titles, more than one way in.

  5. 05
    Judgement

    Optionally, Claude decides what rules can't: is this alt text useful? Is "click here" clear?
